# PanelVault — Lector Personal de Cómics PDF

Aplicación web interactiva y responsiva para gestionar y leer cómics en formato PDF desde el navegador web y dispositivos móviles.

## Características
- **Optimizado para móviles**: Navegación táctil con gestos de deslizamiento (*swipe*), toque central para lectura inmersiva a pantalla completa y doble toque para zoom.
- **Múltiples modos de lectura**: Página única, doble página (spread), cascada continua (*webtoon*) y modo manga (lectura derecha a izquierda).
- **Almacenamiento local persistente**: Guardado de cómics en el navegador mediante IndexedDB.
- **Filtros y personalización**: Temas oscuro, OLED medianoche, sepia y modo inversión nocturna.

## Despliegue en Render
1. Conecta este repositorio en [Render](https://render.com/).
2. Selecciona **Static Site** (Sitio Estático).
3. **Build Command**: déjalo vacío.
4. **Publish Directory**: pon `.`
5. Haz clic en **Create Static Site**.
